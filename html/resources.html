🔌 NASA APIs Used in This Project

This application utilizes several NASA Open Data APIs to provide real-time space information:

Astronomy Picture of the Day (APOD)

Daily featured astronomy images with detailed explanations from NASA scientists.

api.nasa.gov/planetary/apod Active
🌌

Near Earth Object Web Service (NeoWs)

Information about near-Earth asteroids and their orbital characteristics.

api.nasa.gov/neo/rest/v1 Active
🌡️

Mars Weather Service API

Latest weather reports from Mars including temperature, pressure, and wind data.
